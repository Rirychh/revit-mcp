Revit MCP 安裝說明
==================

讓 Claude Desktop 直接讀取與操作開著的 Revit 模型（查元件、建模、出圖、標註、模型健檢等）。
支援 Revit 2022、2023、2024、2025、2026、2027，會自動裝到這台電腦有的版本。
版本：v1.10.4（2026-11-11），共 170 個工具。

【可以做什麼】
- 文件與專案：開檔、存檔、與中央同步、專案資訊與單位、專案參數、階段、工作集
- 建模：牆、樓板、柱、梁、網格、標高、門窗、天花、屋頂、開口、樓梯、欄杆、帷幕牆格線與豎框、牆附著
- 編輯：移動、旋轉、鏡射、陣列、複製、換類型、複製類型、構造層、材料、群組、接合、刪除
- 視圖與註解：視圖、立面、詳圖索引、視圖範圍、篩選器、視圖樣板、標籤、尺寸、文字、高程點、填滿區域、修訂雲形線
- 圖紙與輸出：圖紙、放置視圖、明細表（含排序與篩選）、PDF／DWG／IFC／NWC 匯出
- 族群：建立族、輪廓族、掃掠（牆飾條、樓板邊緣、封簷板、排水溝）、族類型參數與公式、清除未使用項目
- 檢查：模型健檢、效能報告、警告、碰撞、材料數量、面積平面
會改動模型的工具都先預檢，確認後才執行；執行失敗會整批復原。
版本限制：牆附著需要 Revit 2025 以上，全面清除未使用項目需要 Revit 2024 以上。

【安裝前】
1. 先存檔、關閉所有 Revit。
2. 這台電腦要已經裝好 Claude Desktop，而且開過一次。
3. 不需要另外安裝 Node.js，也不需要系統管理員權限。

【安裝】
1. 把整個 zip 解壓縮到任何資料夾（不要直接在 zip 裡面點）。
2. 雙擊「_雙擊我_RevitMCP安裝.hta」。
3. 按「安裝」。完成後：
   - 重新開啟 Revit；
   - 完全關閉 Claude Desktop（右下角系統匣圖示也要結束）再重新開啟。
4. 在 Claude Desktop 對話中說「列出 Revit 裡的樓層」測試。

【Revit 裡的對話面板：Claude／GPT／Gemini】
面板上方「AI」選單可切換 Claude、GPT、Gemini，各家金鑰分開存（Windows 認證管理員）。
- Claude：Anthropic API 金鑰（console.anthropic.com）
- GPT：OpenAI API 金鑰（platform.openai.com）
- Gemini：Gemini API 金鑰（aistudio.google.com）
「模型」欄可改模型 ID，按 Enter 套用；清空再按 Enter 恢復預設。切換 AI 會重新開始對話。

【搭配 Gemini CLI 或 Codex CLI（GPT）】
安裝程式只會自動設定 Claude Desktop。其他 AI 工具要手動加設定，路徑中的 <帳號> 換成自己的 Windows 帳號名稱。

Gemini CLI：編輯 %USERPROFILE%\.gemini\settings.json，加入：
  {
    "mcpServers": {
      "revit": {
        "command": "C:\\Users\\<帳號>\\AppData\\Local\\Rirychh\\RevitMCP\\node\\node.exe",
        "args": ["C:\\Users\\<帳號>\\AppData\\Local\\Rirychh\\RevitMCP\\server\\dist\\index.js"],
        "timeout": 600000
      }
    }
  }
  檔案裡已有其他設定時，只把 "revit" 這段併進既有的 "mcpServers"。

Codex CLI：編輯 %USERPROFILE%\.codex\config.toml，加入：
  [mcp_servers.revit]
  command = 'C:\Users\<帳號>\AppData\Local\Rirychh\RevitMCP\node\node.exe'
  args = ['C:\Users\<帳號>\AppData\Local\Rirychh\RevitMCP\server\dist\index.js']
  tool_timeout_sec = 600

設定完重開 Gemini CLI／Codex，說「列出 Revit 裡的樓層」測試。
ChatGPT 網頁版／桌面版只能接遠端伺服器，不能接這個本機版本。

【常見問題】
- 「Revit 還開著」：請完全關閉 Revit（工作管理員裡也不能有 Revit.exe）。
- 「找不到 Claude Desktop 的設定資料夾」：先安裝 Claude Desktop 並開過一次。
- Revit 2022 有舊版裝在 ProgramData 時，安裝程式會把舊的停用；若提示需要系統管理員權限，
  請在 HTA 檔上按右鍵「以系統管理員身分執行」。

【移除】
執行同一個安裝程式，按「移除 Revit MCP」。

【檔案位置】
- Revit 外掛：%APPDATA%\Autodesk\Revit\Addins\<版本>\RevitMcpAddin\
- MCP 伺服器：%LOCALAPPDATA%\Rirychh\RevitMCP\
- 安裝紀錄：%TEMP%\revitmcp_install.log

【命名設定】
安裝時會放一份 %LOCALAPPDATA%\revit-mcp\naming.json（已有就不覆蓋）：
- familyPrefix：新建族的前綴（build_family、輪廓族、量體都會自動補上，已帶前綴就不重複加）
- profilePrefix / massPrefix：輪廓族、量體另外指定前綴；null 表示沿用 familyPrefix
- textType：圖紙修訂說明的預設文字類型；revisionCloudTextType：雲形註記的預設文字類型
- titleBlocks：圖紙修訂說明寫進各圖框的座標（mm，相對圖框插入點），換圖框時在這裡加
改完存檔即生效，不用重開 Revit。刪掉這個檔就不套用任何前綴與預設。
