Revit MCP – Help

Revit MCP connects AI assistants to Autodesk Revit. Use it in two ways: chat inside Revit with your own API key, or control Revit from Claude Desktop through the Model Context Protocol (MCP).

Safety

Tools that change the model run as a preview by default (apply=false). Claude shows what will change; the change is made only after you confirm. Each call runs in one transaction and rolls back fully on any error.

Privacy

The add-in listens on 127.0.0.1 only (ports 48884+, token-protected) and sends no telemetry. When you use AI Chat, your prompts and the model data needed to answer them go to the AI provider you selected, under that provider's terms. API keys are stored in Windows Credential Manager.

Several Revit sessions

Each Revit instance takes the next free port from 48884. Ask Claude to “list Revit instances” and pick one.

Uninstall

Windows Settings → Apps → Revit MCP → Uninstall. To remove the Claude Desktop entry, delete "revit" under mcpServers in claude_desktop_config.json (a backup .bak-revitmcp is created when you connect).
